AGENT CONTROL CENTER · WEB ACCESS

把你的 Agent
帶到瀏覽器。

這個入口頁適合放在 GitHub Pages。真正的網頁版由你的 Agent 主機提供，因此只要貼上主機公開網址，就能從手機、平板或電腦開啟。

開啟網頁版

請輸入主機公開網址，例如 https://your-agent.example.com。系統會開啟主機的 /net/app/ 網頁版。

注意：GitHub Pages 是靜態託管，不能取代執行 Node.js 後端的 Agent 主機。

Android APK含內建 PRoot 的手機版，適合直接在 Android 執行。
深色介面延續原專案的暗色系 UI，適合長時間操作。
安全提醒請只輸入你信任的 HTTPS 主機網址，不要把 API 金鑰放到 Pages。
